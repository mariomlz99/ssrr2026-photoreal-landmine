# Supplementary material

This directory contains reviewer-motivated analyses and qualitative material that support the camera-ready paper but are not included in the 8-page manuscript.

- [`appearance_adaptation_control/`](appearance_adaptation_control/) — synthetic Baseline-30k with the extra adaptation stage removed.
- [`real_appearance_adaptation_control/`](real_appearance_adaptation_control/) — real-data YOLO11l trained with the same extra adaptation stage used by the synthetic pipeline.
- [`hirescam/`](hirescam/) — qualitative HiResCAM examples retained for inspection and presentation; illustrative only.

All headline paper metrics remain in [`eval_results/`](../eval_results/) and [`results/`](../results/).
